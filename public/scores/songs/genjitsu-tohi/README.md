# げんじつとーひこう！

アーティスト: 千代園るる  
アルバム: 魔法つかいにならないで  
BPM: 162 (推定値)

## 音声ファイルの追加

`audio.ogg` は `mahou-tsukai-player` リポジトリのWAVファイルをOGGに変換して追加してください。

```bash
ffmpeg -i <source>.wav public/scores/songs/genjitsu-tohi/audio.ogg
```

## 注意事項

- `score.musicxml` はプレースホルダーです。正式な譜面に差し替えてください。
- BPMは推定値です。実際の音声を確認して調整してください。
